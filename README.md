# NEXUS // Minimalist Modern Productivity Workspace

> Modern Minimalist UI built with Python FastAPI, Vanilla JavaScript, and Tailwind CSS.
> **Design**: Rule-of-Thirds Grid, Crisp White & Electric Blue palette, Plus Jakarta Sans typography.

## Quickstart

### 1. Direct Browser Launch (Fastest)
Double-click `index.html` to run in your browser immediately.

### 2. Full FastAPI Server
```bash
pip install fastapi uvicorn pydantic
python main.py
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser.

---

## Core Capabilities

1. **Rule of Thirds Layout**:
   - 1/3 Context & Productivity Scorecard | 2/3 Active Execution Workspace.
   - 1/3 Document Hierarchy Tree | 2/3 Markdown Editor (Split/Write/Preview).

2. **Color Palette & Typography**:
   - Crisp Whites (`#FFFFFF`, `#F8FAFC`) with Electric & Royal Blue accents (`#2563EB`, `#EFF6FF`).
   - Ultra-clear typography: **Plus Jakarta Sans** + **JetBrains Mono**.

3. **Natural Language Smart-Parsing**:
   - Master input bar & Quick-Capture modal parses inputs like:
     - `Code Python at 3pm #dev !high 45m`
     - `Architecture team sync at 11:30am #sync`
   - Real-time live extraction preview.

4. **Autonomous Time-Blocking**:
   - Automatically maps tasks with times into 24-hour timeline blocks (06:00–23:00).
   - "Auto-Schedule All Tasks" button packs remaining items into open slots.

5. **Time-Aware Dynamic Views**:
   - **Morning (06:00-12:00)**: *Focus View* (Top 3 critical priorities).
   - **Afternoon (12:00-18:00)**: *Execution View* (Kanban board + timeline).
   - **Evening (18:00-24:00)**: *Review View* (Velocity progress + evidence log).
   - *Time Simulator pills*: Easily preview all three views at any hour.

6. **Native Focus Engine (Pomodoro Modal)**:
   - Click `[⚡ Focus]` to open fullscreen Pomodoro timer with backdrop blur. Press `Esc` to exit.

7. **Quick-Capture Hotkey**:
   - Press `Ctrl + Space` anywhere to immediately open the accelerator modal.
